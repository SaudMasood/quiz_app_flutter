# 📱 About QuizWins

**QuizWins** is a Flutter-based interactive quiz application developed as part of my **Week 3 Flutter Development Internship at Owasoft Technologies Pvt. Ltd.**

The application allows users to select a quiz category, answer multiple-choice questions, receive immediate feedback, calculate their score, view the final result, and review their previous quiz attempts through the History section.

The project was developed not only to create a functional quiz application but also to gain practical experience with a structured Flutter architecture.

During development, I worked with:

- Flutter
- Dart
- BLoC State Management
- Events and States
- Equatable
- Model Classes
- SQLite
- Sqflite
- Async/Await
- Local Data Persistence
- Navigation
- Reusable Widgets
- Feature-Based Project Structure

# 🎯 Project Objectives

The main purpose of this Week 3 project was to develop a functional Flutter application while improving practical knowledge of application architecture and local data management.

### Main objectives:

- Build a complete quiz application
- Create a clean and organized Flutter project
- Implement multiple quiz categories
- Store questions locally
- Retrieve questions from SQLite
- Display questions dynamically
- Handle multiple-choice answers
- Validate selected answers
- Calculate quiz scores
- Save quiz results
- Display completed quiz results
- Create a quiz history section
- Practice BLoC state management
- Separate UI from business logic
- Use model classes for structured data
- Create reusable widgets
- Improve navigation and user experience

# ✨ Main Features

## 🏠 Home Screen

The Home Screen acts as the main entry point of the quiz application.

Users can see the available quiz categories and select the quiz they want to attempt.

Each category card contains:

- Quiz title
- Category name
- Number of questions
- Category icon
- Navigation to Quiz Screen
